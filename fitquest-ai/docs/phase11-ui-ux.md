# Phase 11 — Minimal / Luxe UI

Theme: ink black, warm ivory, single champagne accent (`#cdb892`), hairline borders.

- Typography: Cormorant Garamond (display) + Inter / Noto Sans Thai (UI), light weights, wide-tracked uppercase labels
- Removed: neon glows, gradients, grid/particle backgrounds, scanlines, emoji icons
- HUD: one slim panel (Score · Reps · Combo · Time) instead of four cards
- Missions: list with 1px progress lines
- Buttons: pill-shaped, ivory solid (primary) / hairline outline (ghost)
- Design tokens live in `:root` of `src/index.css` (`--fq-*`)
