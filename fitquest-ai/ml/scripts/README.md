# ML scripts

The scripts in this directory prepare datasets, train and evaluate the 1D CNN, and generate reports.

For the current eight-class model, use the up-to-date instructions in [`ml/README.md`](../README.md). That guide documents:

- the real-only `combined-real-8class` dataset and its input layout
- dataset preparation with `build_real_8class_dataset.py`
- training and browser-model export with `train_cnn.py`
- metrics, reports, and CNN runtime verification

Run commands from the repository root so the documented paths resolve correctly.
